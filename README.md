## Project Overview

Doggy Doggy is a full-stack web application developed for a real client to establish a professional online presence and deliver a modern digital ordering experience.

The platform combines a responsive customer-facing website with backend services, database integration, authentication, and order-management functionality. It was designed to provide customers with an intuitive browsing and ordering experience while supporting the business through integrated application features.

As the developer responsible for the implementation, I worked across the application stack, from frontend development and interactive functionality to API integration, database connectivity, authentication, deployment, and custom-domain configuration.

This project demonstrates practical experience delivering a client-oriented web application that integrates multiple technologies into a cohesive solution.

## My Role & Responsibilities

As the developer of Doggy Doggy, I was responsible for implementing and integrating the application's core components.

- **Frontend Development:** Designed and developed the website interface using HTML5, CSS3, and JavaScript.
- **Responsive Design:** Implemented responsive layouts and interactions for desktop and mobile devices.
- **Interactive Shopping Cart:** Developed dynamic cart functionality, quantity controls, and add-to-cart interactions.
- **Menu & Product Presentation:** Implemented interactive product browsing with images and descriptions.
- **Backend Development:** Built backend API functionality using Python and FastAPI.
- **Database Integration:** Integrated Supabase and PostgreSQL for application data management.
- **Authentication:** Implemented authentication-related functionality and integrated user account workflows.
- **Order Processing:** Connected customer-facing order workflows with backend API endpoints.
- **Administrative Functionality:** Developed administrative features for product and order management.
- **API Integration:** Connected frontend components to backend services using HTTP requests and JSON.
- **Security Configuration:** Worked with authentication, JWT-based security, environment variables, and CORS configuration.
- **Deployment:** Deployed the frontend using Vercel and the backend using Render.
- **Custom Domain:** Configured the application for a custom domain and handled deployment-related DNS troubleshooting.
- **Testing & Debugging:** Investigated technical issues, tested application behavior, and refined functionality throughout development.

## Application Architecture

The application uses a separated frontend and backend architecture, with database and authentication services supporting the application's workflows.

### 1. Frontend Layer

The frontend provides the customer-facing interface, menu browsing, shopping cart, account forms, and interactive website components.

### 2. Backend Layer

The Python and FastAPI backend provides API endpoints that connect frontend actions with application logic and data operations.

### 3. Database & Authentication Layer

Supabase and PostgreSQL support persistent application data and authentication-related functionality.

### 4. Deployment Layer

The frontend and backend are deployed as separate services using Vercel and Render. GitHub provides source-code version control and supports the development and deployment workflow.

## Technical Implementation

### Frontend Engineering

The frontend was implemented using HTML, CSS, and vanilla JavaScript. Interactive components were developed to support product selection, shopping cart updates, form interactions, and responsive layouts.

### Backend Integration

The frontend communicates with backend API endpoints to support application functionality, including product and order workflows. Production API configuration replaces local development endpoints where appropriate.

### Authentication & Security

Authentication functionality is integrated with the application's account workflows. Backend security configuration includes JWT-related functionality, environment-based configuration, and cross-origin request policies.

Sensitive credentials and user information are not included in the public repository documentation.

### Production Deployment

The application is deployed using Vercel for the frontend and Render for the backend. Deployment work includes production API configuration, environment setup, frontend-backend connectivity, and custom-domain configuration.
